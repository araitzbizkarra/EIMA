# AZTARNA · Zortzi leku, istorio bat

DBH3, DBH4 Matematika A eta DBH4 Matematika B ikasgaietarako euskarazko abentura matematikoaren demoa. Bi misio jokagarri ditu: Zumaia eta Gesaltza Añana. Mapak proiektuaren zortzi kokalekuak erakusten ditu; gainerako sei misioak garatzeko daude.

## GitHub Pages-en argitaratu

1. Deskargatutako ZIPa **erauzi**. Ireki `index.html` dagoen karpeta.
2. GitHuben sortu `aztarna-demo` izeneko biltegi **publiko** bat. GitHub Free-rekin Pages erabiltzeko, biltegi publikoa behar da.
3. Biltegi berrian sakatu **uploading an existing file**, edo **Add file → Upload files**. Arrastatu karpetaren **barruko fitxategiak eta `assets` karpeta**. `index.html` biltegiaren lehen mailan gelditu behar da, `README.md`-ren ondoan. Ez igo ZIPa bera eta ez sartu dena beste karpeta baten barruan.
4. Gorde fitxategiak **Commit changes** aukerarekin, `main` adarrean. Aldaketak beste adar batera bidaltzen badituzu, bateratu `main` adarrera.
5. Ireki **Settings → Pages**. Hautatu **Source: Deploy from a branch**, **Branch: main** eta **Folder: /(root)**. Sakatu **Save**.
6. Argitalpena amaitzean, ireki **Settings → Pages → Visit site** eta kopiatu bertako esteka. URLaren egitura hau izango da: `https://ZURE-ERABILTZAILEA.github.io/aztarna-demo/`. Adibidearen ordez, erabili GitHubek emandako benetako helbidea.

## Aurkeztu aurretik

Ireki esteka ezkutuko leiho batean. Probatu hasiera, pertsonaia, mapa, lehen erronka, Añanako misioa eta koadernoaren deskarga. EIMAko txostenaren 4.3 ataleko «Demoaren url-a» eremuan **webgunearen esteka** jarri, ez biltegiaren helbidea. Worda aldatu ondoren, PDFa ere eguneratu.

## Edukia eta erabilera

- `index.html`: jokoaren sarrera.
- `game.css`, `.js` fitxategiak eta `assets/`: jokoaren kodea eta irudiak.
- `gida.html`: irakaslearen gida eta erantzunen erreferentziak.
- `iturriak.html`: iturriak, lizentzia eta kredituak.
- `.nojekyll`: fitxategi estatikoak zuzenean argitaratzeko marka; ez du edukirik.

Ez da instalaziorik, konpilaziorik, API gakorik edo ikasle-konturik behar. Aurrerapena nabigatzailean gordetzen da; irakasleari ez zaio automatikoki bidaltzen. Koadernoa deskargatu eta irakasleari eman daiteke. Aurreko beste domeinu batean gordetako aurrerapena ez da helbide berrira automatikoki eramaten.

Demoan aldaketak argitaratzeko, ordezkatu dagokien fitxategiak `main` adarrean. Pages-ek argitalpena eguneratuko du. Itxura zaharra agertuz gero, kargatu berriz orria `Ctrl+F5` erabiliz.
